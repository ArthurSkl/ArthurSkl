## 🧪 Engenharia de Qualidade & Automação de Testes (QA)

- **Pirâmide de Testes em 3 Camadas:** Implementação prática combinando testes **Unitários (`node:test` / JUnit)**, **Integração & Contrato de API (`Supertest`)** e **End-to-End (`Cypress` / `Selenium WebDriver`)**.
- **Integração Contínua (CI/CD):** Execução automatizada de suítes de teste a cada push/PR via **GitHub Actions**, com geração de evidências (screenshots e vídeos).
- **Documentação & Processos Ágeis:** Elaboração de Planos de Qualidade (`QA.md`), matrizes de risco, critérios de aceite, casos de teste estruturados (`TEST_CASES.md`) e testes regressivos/exploratórios.
